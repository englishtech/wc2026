## Прогноз исходов матчей финальной стадии ЧМ-2026 по футболу.

**1. Парсинг eloratings.net** (независимый проект, рассчитывающий рейтинг силы футбольных сборных и клубов по модифицированной системе Эло (учитывает результат, важность матча и разницу мячей))
Собраны ~2500 матчей квалификации к ЧМ2026 (`selenium`). Данные включают счёт, рейтинг команд и дату игры.

**2. Очистка данных** (`pandas`): Удалены товарищеские матчи и дубликаты.

**3. Рыночные стоимости**: Собраны текущие цены составов с Transfermarkt (крупнейшая база данных о трансферах, рыночной стоимости игроков и контрактах, используемая как справочник для оценки финансового потенциала команд.), сконвертированы в числа.

**4. Подбор признаков** (`pandas`).
Для обучения использовались признаки:  
`home_elo_rating` - рейтинг ELO в очках  
`away_elo_rating` - рейтинг ELO в очках  
`home_elo_rank` - место команды в рейтинге  
`away_elo_rank` - место команды в рейтинге  
`home_market_value` - рыночная стоимость команды  
`away_market_value` - рыночная стоимость команды  
`bal_market_value` - доля стоимости хозяев в общей стоимости матча (0.0–1.0)  
`prev_N_pts_H` - сумма очков за последние N матчей  
`prev_N_pts_A` - сумма очков за последние N матчей  
`avg_goals_for/against` - средние забитые/пропущенные голы команды за последние N матчей  
`goal_diff` - разница забитых/пропущенных голов команды  
`clean_sheet` - Доля матчей без пропущенных голов за последние N игр  
`is_neutral` - 1 если location != home_team, иначе 0  
\+ целевая переменная `result` - 1=победа Х, 2=победа Г, 0=ничья  

> Были оставлены только elo-признаки (рейтинг ELO в очках и место команды в рейтинге)

**5. Работа с моделью** (`sklearn`).

- bal_market_value, home_market_value, away_market_value имели веса ≈ 0, дублируют сигнал Elo → удалены.
- avg_goals_for/against, goal_diff, clean_sheet не дали прироста, модель предпочла «очки» детальной статистике → удалены.
- elo_diff как замена раздельным рейтингам ухудшил стабильность (разброс CV ±1.77% → ±4.97%) → вернулся к home_elo + away_elo.
- is_neutral → убран, в финальной части не роляет.

Модель давала существенный перевес в П1, так как на этапе квалификации соотношение по матчам было в пользу П1 (Н 575, П1 1451, П2 482).

**6. Итоговая конфигурация**:

**Данные**: все матчи (2508 матчей, без фильтра по турниру, исключены только товарищеские)  
**Признаки**: home_elo_rating, away_elo_rating, home_elo_rank, away_elo_rank  
**Модель**: LogisticRegression + StandardScaler  
**Разделение**: train = 2006, test = 502 (80/20, для финальной модели взяты все 100% данных)  
**Точность на тесте**: 60.76%  
**Точность кросс-валидации**: 68.10% ± 1.37% (n_splits=5)  

> Введен class_weight='balanced' для балансировки ошибок и штрафа за неправильный прогноз на П2.
